# Beyond Earth — Orbital Portal

Interactive 3D space portal with the ORION Enderman companion, Ender Dragon flight simulation, and real-time orbital telemetry visualization.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- Three.js WebGL 3D character & orbital rigs

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
