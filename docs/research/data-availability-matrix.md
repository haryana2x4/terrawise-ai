# Data Source Availability Matrix
*Evaluation for Ahilya Nagar & Nashik Pilot Platform*

| Data Provider / Source | Agronomic & Geo Parameters | Spatial Resolution | Temporal Resolution | Latency | Access Method & Auth | Licence / Terms | Rate Limits | Decision & Integration Architecture |
|---|---|---|---|---|---|---|---|---|
| **Open-Meteo** (Forecast & Historical) | 2m Temp, Max/Min Temp, Rain, RH, Wind Speed, Soil Moisture (0-7cm, 7-28cm, 28-100cm), Soil Temp | ~1 km (interpolated) | Hourly / Daily 7-day forecast | <1 hour | REST API; No API Key required | Non-commercial free tier / CC BY 4.0 attribution | 10,000 calls/day | **USE**: Primary live weather & soil moisture engine. Cached per farm centroid on 3-hour TTL. |
| **NASA POWER** (Agroclimatology) | Daily solar radiation (`ALLSKY_SFC_SW_DWN`), precip (`PRECTOTCORR`), root wetness (`GWETROOT`), surface wetness (`GWETTOP`), VPD, GDD | 0.5° × 0.625° | Daily | 24–48 hours | REST API; Open access, no key | NASA Open Data Policy / Public Domain | ~30 req/min | **USE**: Primary climate history & root-zone water balance model. Queried once daily per parcel centroid. |
| **NASA GIBS** (Global Imagery Browse Services) | Satellite base tiles: MODIS NDVI, SMAP soil moisture, IMERG 24hr precipitation | 250m to 10km | Daily / 8-day composite | 3–12 hours | WMTS / XYZ Slippy Map Tiles | NASA Open Access | Open, standard CDN | **USE**: Satellite layer overlays on interactive field map. |
| **Google Maps JavaScript API** | Satellite imagery base, hybrid roads/labels, Data Layer polygon rendering | Sub-meter satellite | Static tile cache | Real-time | JS SDK; Requires Google Maps API Key | Proprietary (Google Cloud Terms) | Quota-based ($200 free monthly credit) | **USE WITH CAUTION**: Primary visual map layer if `VITE_GOOGLE_MAPS_KEY` is present. If missing, automatically fall back to Leaflet + OpenStreetMap + NASA GIBS. |
| **OpenStreetMap & Overpass API** | Baseline administrative vector map, road networks, cadastral context | Vector | Community live edits | Live | Tile server / Overpass QL | Open Database License (ODbL) | 1 req/sec on public Overpass | **USE**: Default map engine fallback and admin boundary source. Mandatory attribution rendered. |
| **Sentinel-2 (Copernicus Data Space)** | 10m Multispectral bands (B4 Red, B8 NIR) -> Zonal NDVI greenness per polygon | 10 meters | 5-day revisit | 12–24 hours | OData / STAC API; Requires CDSE OAuth account | Open & Free EU Copernicus Policy | 4 req/sec authenticated | **USE WITH CAUTION**: Requires registered user credentials. Integrated as optional cloud-masked NDVI pipeline. |
| **Agmarknet (via data.gov.in)** | Daily arrival quantities and Min/Modal/Max prices for Lasalgaon, Pimpalgaon, Rahuri, Nashik APMC | Market yard specific | Daily (afternoon) | 4–8 hours | REST API; Requires data.gov.in API Key | National Data Sharing and Accessibility Policy (NDSAP) | 1,000 req/day | **USE WITH CAUTION**: Key documented in `/docs/setup-keys.md`. When key is absent, served with historical benchmark range. |
| **IMD District Agromet & Warnings** | District rainfall normals, weekly agro-advisories, orange/red alerts | District level | Weekly (Tues/Fri) | 12 hours | PDF bulletins / RSS feeds | IMD Public Domain | No programmatic API | **USE WITH CAUTION**: Synthesized as rule triggers in risk engine. Automatic bulletin scraper documented. |
| **Maharashtra CROPSAP & Mahavedh** | Taluka-level pest incidence (stem fly, thrips, bollworm) & automatic weather stations | Circle / Taluka | Weekly / Hourly | 24 hours | Government portal | Maharashtra Dept. of Agriculture | No public open REST API | **SKIP PROGRAMMATIC SCRAPING**: Terms do not offer public open API. Offline reference incorporated into pest calendar. |
| **CGWB Groundwater Dynamic Assessment** | Groundwater extraction stage, over-exploited taluka classification | Taluka level | Annual / Multi-year baseline | Yearly | Public reports (CGWB portal) | Ministry of Jal Shakti Open Data | Static reference | **USE**: Static reference database per taluka linked in advice engine. |
| **SoilGrids (ISRIC)** | Soil texture (clay/silt/sand fraction), Organic Carbon (SOC), Bulk density, pH | 250 meters | Static baseline (v2.0) | Static | REST API / Web Coverage Service (WCS) | CC BY 4.0 | Open access | **USE**: Baseline soil profile initialization when farmer has not entered soil lab card. |
